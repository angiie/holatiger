六个真正会用到的功能

没有账号、没有云同步开关、没有埋点。

01

一键收集

按域名规则收集当前窗口或全部窗口，自动去重，重复链接直接跳过。

02

数据留在本机

收藏、规则、设置都存在 chrome.storage.local，卸载即删。

03

中文优先摘要

抓取 GitHub README 时优先用中文版本，生成一段能直接读的摘要。

04

GitHub 增强搜索

按语言、star、fork 筛选仓库，选中的结果直接收进收藏库。

05

导出与备份

Markdown 清单或完整 JSON 备份，随时导入还原。

06

可选 Gist 同步

填自己的 GitHub Token，备份写进你账号下的私有 Gist，多设备共用。

隐私很简单

默认不联网、不统计、不追踪。只有你主动用 GitHub 搜索、README 摘要或 Gist 同步时，才会直接请求 api.github.com。
