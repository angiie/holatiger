Omnipotent-Pocket · Chrome Extension

隐私政策 / Privacy Policy

Omnipotent-Pocket 是一个只在本机工作的标签页收藏扩展。默认情况下，它不向任何服务器发送数据。

最后更新：2026-11-12 · 适用于扩展版本 1.0.x

1. 我们不收集什么

  • 没有账号体系，没有注册、登录或用户画像。
  • 没有统计、埋点、崩溃上报或广告 SDK。
  • 没有中转服务器：扩展不经过我们自建的任何后端。

2. 保存在你本机的数据

收藏的链接（网址、标题、域名、摘要、时间）、域名过滤规则和扩展设置，全部保存在浏览器的 chrome.storage.local 中。它们只存在于这台设备的浏览器配置里，卸载扩展或清除扩展数据即被删除。

3. 可选的 GitHub Gist 同步

这是一个需要你手动开启的功能，默认关闭。开启后：

  • 你需要在设置里填入自己的 GitHub Personal Access Token（仅需 gist 权限）；
  • Token 与备份内容只保存在本机，并以你的身份直接请求 api.github.com；
  • 备份写入你账号下的 Gist，数据流向由 GitHub 的隐私政策约束，我们无法读取；
  • 随时可以在设置中清除 Token 并停止同步。

4. 访问 GitHub 的请求

当你使用「GitHub 搜索」或为仓库生成 README 摘要时，扩展会直接向 api.github.com 和 raw.githubusercontent.com 请求公开数据。请求只包含你要查询的仓库或关键词，不包含你的浏览历史，也不会附带身份信息。

5. 权限说明

  • tabs：读取当前打开的标签页标题与网址，用于「收集标签页」；
  • storage：在本机保存收藏、规则与设置；
  • api.github.com、gist.githubusercontent.com：上面第 3、4 条描述的 GitHub 请求。

6. 数据删除

在扩展设置中可一键清空收藏与规则；移除扩展会删除全部本地数据。若你开启过 Gist 同步， 备份文件位于你自己的 GitHub 账号，需要你在 GitHub 上删除。

7. 政策变更与联系

功能变化导致数据处理方式改变时，本页面会更新并修改顶部的更新日期。问题或建议请通过 github.com/angiie 联系。

Privacy Policy (English)

Last updated: 2026-11-12 · Applies to version 1.0.x

1. What we do not collect

  • No accounts, sign-ups or user profiles.
  • No analytics, telemetry, crash reporting or advertising SDKs.
  • No relay server: the extension never talks to a backend we operate.

2. Data stored on your device

Saved links (URL, title, domain, summary, timestamps), domain filter rules and settings live in chrome.storage.local. They stay inside this browser profile and are deleted when you remove the extension or clear its data.

3. Optional GitHub Gist sync

This feature is off by default and must be enabled explicitly. When enabled:

  • you paste your own GitHub Personal Access Token, scoped to gist only;
  • the token and the backup never leave your device unencrypted and are sent directly to api.github.com as you;
  • the backup is written to a Gist in your own account, governed by GitHub's privacy policy — we cannot read it;
  • you can clear the token and stop syncing at any time in settings.

4. Requests to GitHub

Repository search and README summaries call api.github.com and raw.githubusercontent.com for public data. Requests contain only the repository or keywords you asked for — never your browsing history or identity.

5. Permissions

  • tabs: read open tab titles and URLs so "Collect tabs" can work;
  • storage: keep your library, rules and settings on this device;
  • api.github.com, gist.githubusercontent.com: the GitHub requests described in sections 3 and 4.

6. Deleting your data

Settings can erase the library and rules at once; removing the extension deletes all local data. If you enabled Gist sync, the backup lives in your own GitHub account and must be deleted there.

7. Changes and contact

If how we handle data changes, this page is updated along with its date. For questions, reach out via github.com/angiie.
