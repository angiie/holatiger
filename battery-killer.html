BatteryKiller 让电池按你设定的区间充放电循环

BatteryKiller 用软件方式控制 MacBook 的电源适配器通断：电量升到区间上限就切断供电让电池真实放电，降到下限再恢复供电重新充电，如此往复。长期插电当台式机用时，电池不再常年顶在 100%。

它是怎么做到的

没有公开 API 可用，所以走的是 SMC 固件加一个最小权限助手这条路。

🔌

控制电源的是 SMC 的 CHIE 键

macOS 没有公开的「断开充电器」接口，真正的开关在 AppleSMC 固件里：写入 CHIE = 0x00 接通适配器，CHIE = 0x08 切断适配器，机器转为电池供电。

🔐

写 SMC 要 root，所以配了常驻助手

非 root 进程能读 SMC，但所有写入都会被内核拒绝。助手 bkhelper 由 launchd 以 root 常驻，对外只有 VERSION / STATUS / ON / OFF 四条指令。

✅

每次写入都读回校验

SMC 固件存在「谎报成功」的情况，所以每次写入之后都会立刻读回比对，确认状态真的切换了才算数。

注意：CHIE 只表示电源通路的意愿，并不代表充电器是否物理接入；后者要看 AC-W 或 IOKit 的电源接口信息。应用基于 SMC 私有键实现，系统固件更新后行为可能变化，风险自负。

适合谁用

只要你的 MacBook 大部分时间插着电，它就派得上用场。

长期插电党：MacBook 一直插着电当台式机用，不想让电量常年顶在 100%。
在意电池健康：想避开长期满电高压带来的鼓包与健康度下降，也不想把电放到空。
需要临时断电：想一键把机器切到电池供电，比如对比功耗、或者出门前先把电耗掉一些。
不爱装全家桶：只想要一个安静的菜单栏小工具，不想要带一堆后台服务的电池管家。

常见问题

关于安装、权限与适用机型的常见疑问。

BatteryKiller 支持哪些机型？

支持 Apple Silicon（arm64）且系统为 macOS 13 及以上的 Mac，Intel Mac 不在支持范围。此外只有在 SMC 的 CHIE 键存在且可写的机型上才能工作，其他机型启动后会直接提示「本机不支持软件控制电源适配器」——这个判断只读 SMC 元信息，不需要 root，所以不会白弹一次授权框。

为什么打开时会提示「无法验证开发者」？

项目没有 Apple 开发者签名，也没有做公证，Release 里的包是 ad-hoc 签名，所以 Gatekeeper 会拦一下。首次打开请右键 → 打开，或者先在终端执行 xattr -rd com.apple.quarantine /Applications/BatteryKiller.app 解除隔离属性。这是本项目的现状而非下载出错，每次升级新版本后都需要再做一次。

为什么首次使用需要输入管理员密码？

因为写入 SMC 必须以 root 身份进行，而图形界面进程始终以登录用户身份运行。应用会把特权助手 bkhelper 安装到 /Library/PrivilegedHelperTools 并交给 launchd 常驻，所以只需要授权这一次，之后不再弹框。

长期使用会不会伤电池？

让电量在区间内往返、避免长期满电，本身就是对电池更友好的用法，循环区间两侧是各自独立的阈值，电量在阈值附近也不会来回抖动。但它基于 SMC 私有键实现，系统固件更新后行为可能变化，风险自负。

退出应用后电源会怎样？

退出应用前会自动恢复墙上供电，不会把机器留在断电状态。另外循环运行期间会申请电源断言，避免机器空闲睡眠导致循环卡住。

会上传我的数据吗？

不会。应用只在本机读取电池状态并读写 SMC，不联网、不收集任何信息，源码在 GitHub 上完全公开。
